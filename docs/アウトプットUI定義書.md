# SFA アウトプットUI定義書

## UI基本方針

- **対象デバイス**：PC中心
- **権限管理**：なし（全メンバーが全画面を閲覧可能）
- **開発優先度**：B（一覧画面）→ A（企業詳細ページ）→ C（全社サマリー）

---

## グローバルナビゲーション（最終版）

```
├─ タスク一覧（Task）          ← 毎日開くメイン画面
├─ 企業一覧（Company）
├─ 商談一覧（Meeting）
├─ 案件一覧（Project）
├─ 求人一覧（Job）
├─ 全社サマリー               ← ダッシュボード（優先度C）
└─ メンバー管理（Member）
```

### B-1. タスク一覧（最優先画面）

**目的**：メンバーが毎朝開いて「今日やること」を確認する画面

#### 月次個人サマリー（画面上部に表示・role別）

**IS**

| 指標 | 内容 |
|------|------|
| アクション数（合計） | 今月の完了Task数 |
| 内訳 | 架電 / メール / フォーム / SNS DM / その他 の種別ごとの件数 |
| アポ設定数 | 今月のMeeting.setter_member_id件数 |
| 有効アポ率 | アポ数のうちdisqualified_reason = nullの割合（%） |

**FS**

| 指標 | 内容 |
|------|------|
| アクション数（合計） | 今月の完了Task数 |
| 内訳 | 架電 / メール / ピック / 社内MTG / 資料作成 / その他 の種別ごとの件数 |
| 商談数 | 今月参加したMeeting数 |
| トス数（DSL） | setter = 自分 かつ project_id != null かつ Project.business_type = DSL のMeeting数 |
| トス数（PERM） | setter = 自分 かつ project_id != null かつ Project.business_type = PERM のMeeting数 |
| トス数（ITSS） | setter = 自分 かつ project_id != null かつ Project.business_type = ITSS のMeeting数 |
| 契約締結数 | 今月ContractLine.status = 締結済になった件数 |

**PERM / ITSS**

| 指標 | 内容 |
|------|------|
| アクション数（合計） | 今月の完了Task数 |
| 内訳 | 架電 / メール / ピック / 社内MTG / 資料作成 / その他 の種別ごとの件数 |
| 接触企業数 | 今月Taskを登録したユニーク企業数 |
| 接触部署数 | 今月Taskを登録したユニーク部署数 |
| 求人取得数 | 今月のJob取得数（JobMember経由） |
| 稼働中求人数 | 求人DBの稼働ステータスより参照（読み取り専用） |
| 鮮度アラート数 | 取得から30日以上経過かつ稼働ステータスが停止の求人数 |

**DSL**

| 指標 | 内容 |
|------|------|
| アクション数（合計） | 今月の完了Task数 |
| 内訳 | 架電 / メール / ピック / 社内MTG / 資料準備 / 開発 / その他 の種別ごとの件数 |
| 提案数 | 今月ステータスが提案中以降になったProject数 |
| 初回商談→提案までの平均日数 | ProjectStatusHistoryより算出（自分担当案件の平均） |
| 提案→本提案までの平均日数 | ProjectStatusHistoryより算出（自分担当案件の平均） |

#### タスク一覧（下部）表示項目

| 項目 | 内容 |
|------|------|

| 関連企業 | 企業名（クリックで企業詳細へ） |

#### フィルター・ソート

| 種類 | 選択肢 |
|------|--------|
| 担当メンバー | 自分のみ / 全員 / メンバー指定 |
| ステータス | 未着手のみ（default） / 完了含む |
| 優先度 | 高 / 中 / 低 |
| 期日 | 今日 / 今週 / 来週 / 期限超過 |
| 関連事業部 | IS / FS / DSL / PERM / ITSS |

#### エンジニア向けメモ
- デフォルト表示：「自分の未着手タスク・期日昇順」
- 期日超過タスクは赤背景で上部に固定表示
- 一覧上で完了チェックをつけられる（ステータスをワンクリックで完了に変更）

## C）全社サマリー（優先度低・1枚の縦長ページ）

**目的**：チーム全体のKPI・活動量・パイプラインを一画面で把握する
**備考**：開発負担が高い場合は後回し可。スプレッドシート連携で代替も可。

---

### C-1. 今月のKPIサマリー（ページ上部）

| 指標 | 内容 |
|------|------|
| 商談設定数（IS） | 今月のMeeting.setter_member_id 集計 |
| 有効商談数（FS） | disqualified_reason = null の商談数 |
| 契約締結数（FS） | ContractLine.status = 締結済 の今月分 |
| 事業部トス数（FS） | 今月作成されたProject数（Meeting起点） |
| DSL提案数 | Project（DSL）のステータスが提案中以降 |
| DSL受注数 / 受注金額 | Project（DSL）.status = 受注 |
| 求人取得数（PERM/ITSS） | 今月のJob作成数 |

---

### C-2. メンバー別活動量

| 指標 | 内容 |
|------|------|
| メンバー名 / role | |
| アクション数 | 今月のTask（完了）件数 |
| アクション種別内訳 | 架電 / メール など種別ごとの件数 |
| 商談設定数 | ISのみ：setter_member_idで集計 |
| 求人取得数 | PERM/ITSSのみ：JobMemberで集計 |
| 受注金額 | DSLのみ |

---

### C-3. DSLパイプライン

| 表示内容 | 内容 |
|---------|------|
| ファネル別案件数 | 提案準備中〜受注 / 失注のステータス別件数 |
| ファネル別提案金額合計 | ステータスごとの提案金額の合計 |
| パイプライン加重金額 | 提案中案件の estimated_revenue × win_rate の合計（今後の受注見込み金額） |

| 平均滞在期間 | ProjectStatusHistoryより各フェーズの平均日数 |

---

### C-4. 企業エンゲージメント（要注意リスト）

| 表示内容 | 内容 |
|---------|------|
| 90日以上未接触企業 | 最終Meeting日から90日以上経過した企業一覧 |

| クロスセル候補 | 1事業のみ締結済み・他事業未着手の企業一覧 |

---

### C-5. PERM / ITSS 接触分析

| 表示内容 | 内容 |
|---------|------|

## エンジニア向け補足

### 各一覧画面の共通仕様

| 仕様 | 内容 |
|------|------|
| ページネーション | 50件ずつ表示 |
| CSV出力 | 全一覧画面にCSVエクスポートボタンを設置 |
| フィルター保存 | よく使うフィルター条件を保存できる |
| カラム表示切替 | 表示するカラムをユーザーが選択できる |

### 全社サマリーの集計仕様

| 仕様 | 内容 |
|------|------|
| 集計期間 | 今月 / 先月 / 四半期 / 年度をトグルで切替 |
| 自動更新 | ページ表示時にリアルタイム集計 |
| スプレッドシート連携 | 全社サマリーのデータをGoogleスプレッドシートにエクスポート可能にする（開発負担軽減のための代替手段として） |
