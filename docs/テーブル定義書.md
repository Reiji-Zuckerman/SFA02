# SFA テーブル定義書

## テーブル一覧

| テーブル名 | 役割 |
|-----------|------|
| Member | 社内担当者 |
| Company | 企業情報 |
| CompanyMember | 企業×担当者（中間テーブル） |
| Contract | 契約管理（1社1レコード） |
| ContractLine | 事業区分ごとの契約進捗 |
| Department | 部署情報 |
| Contact | 企業担当者情報 |
| Meeting | 商談記録 |
| MeetingMember | 商談×自社メンバー（中間テーブル） |
| MeetingContact | 商談×クライアント担当者（中間テーブル） |
| Project | 案件管理 |
| ProjectStatusHistory | プロジェクトステータス変更履歴 |
| Job | 求人管理 |
| JobMember | 求人×取得メンバー（中間テーブル） |
| JobContact | 求人×担当者（中間テーブル） |
| Task | ToDo / アクションログ管理 |

## 各テーブル定義

---

### Member（社内担当者）

| カラム名 | 型 | NULL | 内容 |
|---------|-----|------|------|
| id | UUID | NOT NULL | 主キー |
| name | STRING | NOT NULL | 氏名 |
| email | STRING | NOT NULL | メールアドレス |
| role | ENUM | NOT NULL | IS / FS / DSL / PERM / ITSS |
| is_active | BOOLEAN | NOT NULL | 在籍フラグ（default: true） |
| created_at | TIMESTAMP | NOT NULL | 作成日時 |
| updated_at | TIMESTAMP | NOT NULL | 更新日時 |

---

### Company（企業情報）

| カラム名 | 型 | NULL | 内容 |
|---------|-----|------|------|
| id | UUID | NOT NULL | 主キー |
| name | STRING | NOT NULL | 企業名 |
| name_kana | STRING | NULL | 企業名カナ |
| industry | ENUM | NULL | 業種 |
| website_url | STRING | NULL | WebサイトURL |
| phone | STRING | NULL | 電話番号 |
| address | STRING | NULL | 住所 |
| lead_source | ENUM | NULL | リード獲得元（テレアポ / 紹介 / 展示会 / Web / その他） |
| referred_by_contact_id | UUID（FK） | NULL | 紹介者のContact ID |
| created_at | TIMESTAMP | NOT NULL | 作成日時 |
| updated_at | TIMESTAMP | NOT NULL | 更新日時 |

**備考**
- 企業全体のステータスは持たない。ContractLine / Project のステータスをUIで表示する
- クロスセル可視化は Company × ContractLine（business_type別）で集計する
- `tier`：求人DBよりJOINで参照。SFA側にカラムなし（読み取り専用）
- `sent_count_90days`（直近90日以内Sent数）：求人DBよりJOINで参照。SFA側にカラムなし（読み取り専用・ITSS/PERMのみ表示）

### Meeting（商談記録）

| カラム名 | 型 | NULL | 内容 |
|---------|-----|------|------|
| id | UUID | NOT NULL | 主キー |
| company_id | UUID（FK） | NOT NULL | Companyテーブル |
| project_id | UUID（FK） | NULL | Projectテーブル（紐付く場合） |
| setter_member_id | UUID（FK） | NOT NULL | 商談取得者（1名） |
| parent_meeting_id | UUID（FK） | NULL | 前回商談ID（商談連鎖の追跡用） |
| meeting_date | DATE | NOT NULL | 商談日 |
| meeting_type | ENUM | NOT NULL | 対面 / オンライン |
| meeting_count | INTEGER | NOT NULL | 商談回数（自動採番） |
| summary | TEXT | NULL | 商談サマリー |
| next_action | TEXT | NULL | ネクストアクション |
| disqualified_reason | ENUM | NULL | 予算なし / 権限者不在 / ニーズなし / タイミング不一致（nullなら有効商談） |
| created_at | TIMESTAMP | NOT NULL | 作成日時 |
| updated_at | TIMESTAMP | NOT NULL | 更新日時 |

**備考**
- `disqualified_reason` が null = 有効商談（デフォルト）
- `disqualified_reason` に値あり = 無効商談
- `meeting_count` は company_id ごとに自動採番する
- **トスの定義**：`setter_member_id` = FSメンバー かつ `project_id` != null = パス確定。project_id が null の場合はパス未確定として扱う

### Project（案件管理）

| カラム名 | 型 | NULL | 内容 |
|---------|-----|------|------|
| id | UUID | NOT NULL | 主キー |
| company_id | UUID（FK） | NOT NULL | Companyテーブル |
| department_id | UUID（FK） | NULL | Departmentテーブル |
| contractline_id | UUID（FK） | NULL | ContractLineテーブル（DSLのみ） |
| business_type | ENUM | NOT NULL | DSL / PERM / ITSS |
| name | STRING | NOT NULL | プロジェクト名 |
| status | ENUM | NOT NULL | ※business_typeによって異なる（下記参照） |
| assigned_member_id | UUID（FK） | NOT NULL | 主担当メンバー（1名） |
| is_active | BOOLEAN | NOT NULL | 継続中フラグ（default: true） |
| win_rate | INTEGER | NULL | 受注確度 0〜100（DSLのみ・手動変更可） |
| estimated_revenue | INTEGER | NULL | 提案金額（DSLのみ） |
| contract_revenue | INTEGER | NULL | 受注金額（DSLのみ） |
| estimated_gross_profit | INTEGER | NULL | 想定粗利（DSLのみ） |
| lost_reason | ENUM | NULL | 予算なし / タイミング / 競合負け / ニーズなし / その他（DSLのみ） |
| created_at | TIMESTAMP | NOT NULL | 作成日時 |
| updated_at | TIMESTAMP | NOT NULL | 更新日時 |

**statusの値（business_typeごと）**

| business_type | status候補 |
|---------------|-----------|
| DSL | 提案準備中 / 提案中 / PoC / 本提案中 / 受注 / 失注 |
| PERM | アプローチ中 / 求人取得 / 停止 |
| ITSS | アプローチ中 / 求人取得 / 停止 |

**備考**
- DSL Project のステータスが「受注」になった際、紐付く ContractLine のステータスを「締結済」に自動更新する（アプリ側ロジック）
- `win_rate` はステータスに応じた初期値を自動セットし、手動上書き可能にする

### Job（求人管理）

| カラム名 | 型 | NULL | 内容 |
|---------|-----|------|------|
| id | UUID | NOT NULL | 主キー |
| project_id | UUID（FK） | NOT NULL | Projectテーブル |
| company_id | UUID（FK） | NOT NULL | Companyテーブル |
| department_id | UUID（FK） | NULL | Departmentテーブル |
| job_title | STRING | NOT NULL | 求人タイトル |
| business_type | ENUM | NOT NULL | PERM / ITSS |
| acquired_date | DATE | NOT NULL | 求人取得日 |
| created_at | TIMESTAMP | NOT NULL | 作成日時 |
| updated_at | TIMESTAMP | NOT NULL | 更新日時 |

**備考**
- 求人DBと同一DB上に構築するため、Job作成時に求人DBへ自動連携する
- ステータス管理は求人DB側で行う
- SENT状況（紹介アクション数）は求人DBをJOINして参照する。SFA側にカラムは持たない（読み取り専用表示）
- 求人鮮度（稼働中かどうか）は求人DBの稼働ステータスをJOINで参照。SFA側にカラムなし（読み取り専用）。acquired_dateから30日経過かつ稼働ステータスが停止の場合にアラート表示
- `project_id` はnullable。Projectに紐づかない単独Jobの登録も可能

### Task（ToDo / アクションログ管理）

| カラム名 | 型 | NULL | 内容 |
|---------|-----|------|------|
| id | UUID | NOT NULL | 主キー |
| title | STRING | NOT NULL | タスクタイトル |
| description | TEXT | NULL | タスク詳細・メモ |
| due_date | DATE | NULL | 期日 |
| status | ENUM | NOT NULL | 未着手 / 完了 |
| priority | ENUM | NULL | 高 / 中 / 低 |
| action_type | ENUM | NULL | 架電 / メール / LinkedIn / フォーム / 訪問 / その他 |
| assigned_member_id | UUID（FK） | NOT NULL | 担当メンバー（1名） |
| company_id | UUID（FK） | NULL | 企業（全Taskを企業単位で集計するため直接持つ） |
| department_id | UUID（FK） | NULL | 部署（PERM/ITSSの部署単位アクション管理用） |
| project_id | UUID（FK） | NULL | Projectテーブル（事業部のTask） |
| contract_id | UUID（FK） | NULL | Contractテーブル（FSのTask） |
| created_at | TIMESTAMP | NOT NULL | 作成日時 |
| updated_at | TIMESTAMP | NOT NULL | 更新日時 |

**備考**
- `project_id` と `contract_id` はどちらか一方のみ入力（両方同時にNOT NULLにならないこと）
- `company_id` は以下のいずれかで必ず特定できること：
  1. `company_id` を直接入力（PERM/ITSSのProject非紐づきアクション）
  2. `project_id` 経由で company が辿れる
  3. `contract_id` 経由で company が辿れる
- `project_id` 選択時は `company_id` / `department_id` を自動セットする（アプリ側ロジック）
- `contract_id` 選択時は `company_id` を自動セットする（アプリ側ロジック）
- どちらも選択しない場合は `company_id` を手動入力必須にする
- 入力UIで「Taskを登録（未着手）」「Actionを登録（完了）」を切り替える
- IS / PERM / ITSSのアクションログもこのテーブルで管理する
- 再アプローチ管理は `contract_id` 紐付きのTaskで行う

## エンジニアへの補足事項

### 自動処理が必要なロジック

| 処理 | トリガー | 内容 |
|------|---------|------|
| DSL受注時のContractLine自動更新 | Project.status = 受注 | 紐付くContractLine.status を「締結済」に更新 |
| ProjectStatusHistoryの自動作成 | Project.status 変更時 | 変更前後のステータスと日時を記録 |
| Meeting.meeting_countの自動採番 | Meeting作成時 | company_id ごとに連番を採番 |
| win_rateの初期値自動セット | Project.status 変更時 | ステータスに応じた確度を自動セット（手動上書き可） |

### バリデーション

| テーブル | カラム | ルール |
|---------|-------|-------|
| Task | project_id / contract_id | 両方同時にNOT NULLにならないこと |
| Task | company_id | project_id / contract_id どちらもNULLの場合は必須 |
| ContractLine | lost_reason | status = リサイクルの場合のみ入力可 |
| Project | win_rate / estimated_revenue 等 | business_type = DSLの場合のみ入力可 |
