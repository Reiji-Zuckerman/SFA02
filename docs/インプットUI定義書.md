# SFA インプットUI定義書

## UI基本方針

- **対象デバイス**：PC中心
- **UIイメージ**：Salesforce的なレイアウト
- **入力起点**：企業詳細ページ起点 / 各オブジェクト一覧起点の両方に対応

---

## グローバルナビゲーション（左サイドバー）

```
├─ ダッシュボード
├─ 企業一覧（Company）
├─ 商談一覧（Meeting）
├─ 案件一覧（Project）
├─ 求人一覧（Job）
├─ タスク一覧（Task）
└─ メンバー管理（Member）
```

---

## 企業詳細ページ構成（SFAの中心画面）

```
企業詳細ページ
  ├─ 基本情報（Company）
  ├─ [タブ] 契約状況（ContractLine × 3事業）
  ├─ [タブ] 部署・担当者（Department / Contact）
  ├─ [タブ] 商談履歴（Meeting）
  ├─ [タブ] 案件（Project）
  ├─ [タブ] 求人（Job）
  └─ [タブ] タスク・アクション（Task）
```

### 4. 契約登録（ContractLine）

| 項目 | 入力タイプ | 必須 | 備考 |
|------|-----------|------|------|
| 企業名 | 企業検索 | ✅ | 企業詳細ページから追加時は自動セット |
| 商談日 | 日付ピッカー | ✅ | |
| 商談形式 | ラジオボタン | ✅ | 対面 / オンライン |
| 商談取得者 | Memberセレクト | ✅ | 1名のみ選択 |
| 参加メンバー（自社） | Member複数選択 | | |

| 関連案件 | Projectセレクト＋新規追加 | | 任意で紐付け（企業に紐づくProjectから選択）/ 「+ 新規案件」から案件名・事業区分のみ入力して仮作成可能。商談登録完了後にProject詳細UIが自動で立ち上がる |

### 6. 案件登録（Project）

**入力タイミング**：企業詳細ページ「案件タブ」から追加 / グローバルナビ「案件一覧」から「+ 新規案件」ボタン

| 項目 | 入力タイプ | 必須 | 備考 |
|------|-----------|------|------|
| 企業名 | 企業検索 | ✅ | 企業詳細ページから追加時は自動セット |
| 事業区分 | セレクトボックス | ✅ | DSL / PERM / ITSS（選択後に以降の項目が動的に変化） |
| 案件名 | テキスト | ✅ | |
| 担当部署 | セレクトボックス | | 登録済み部署から選択 |
| 主担当メンバー | Memberセレクト | ✅ | 1名のみ |
| ステータス | セレクトボックス | ✅ | 事業区分によって選択肢が変化（下記参照） |
| 受注確度 | スライダー（0〜100%） | | DSLのみ表示。ステータス変更時に初期値を自動セット・手動上書き可 |
| 提案金額 | 数値入力（円） | | DSLのみ表示 |
| 受注金額 | 数値入力（円） | | DSLのみ・ステータス = 受注 時に表示 |
| 想定粗利 | 数値入力（円） | | DSLのみ表示 |
| 失注理由 | セレクトボックス | | DSLのみ・ステータス = 失注 時に表示（予算なし / タイミング / 競合負け / ニーズなし / その他） |
| 関連契約 | ContractLineセレクト | | DSLのみ表示（当該企業のDSL ContractLineから選択） |
| 継続中フラグ | トグル | ✅ | default: ON |

**ステータス選択肢（事業区分別）**

| 事業区分 | ステータス選択肢 |
|---------|---------------|
| DSL | 提案準備中 / 提案中 / PoC / 本提案中 / 受注 / 失注 |
| PERM | アプローチ中 / 求人取得 / 停止 |
| ITSS | アプローチ中 / 求人取得 / 停止 |

### 7. 求人登録（Job）

**入力タイミング**：案件詳細ページから「+ 求人追加」ボタン / グローバルナビ「求人一覧」から「+ 新規求人」ボタン / 企業詳細ページ「求人タブ」から「+ 求人追加」ボタン

| 項目 | 入力タイプ | 必須 | 備考 |
|------|-----------|------|------|
| 企業名 | 企業検索 / 自動入力 | ✅ | 企業詳細・案件詳細ページから追加時は自動セット。求人一覧からの新規登録時は手動検索 |
| 関連案件 | Projectセレクト | | 任意。案件詳細ページから追加時は自動セット。Project非紐づきJobも登録可 |
| 事業区分 | セレクトボックス / 自動入力 | ✅ | 関連案件選択時は親Projectから自動セット。未選択時は PERM / ITSS から手動選択 |
| 求人タイトル | テキスト | ✅ | |
| 取得日 | 日付ピッカー | ✅ | |
| 取得担当者 | Member複数選択 | ✅ | |
| 担当部署 | セレクトボックス | | 登録済み部署から選択 |
| 先方担当者 | Contact複数選択 | | 登録済みContactから選択 |
| SENT状況 | 読み取り専用 | | 求人DBのsent数を自動参照・表示。SFA側での入力不要 |

### 8. タスク / アクション登録（Task）

**入力タイミング**：全詳細ページの共通「+ タスク追加」ボタン / グローバルナビ「タスク一覧」から「+ 新規タスク」ボタン

| 項目 | 入力タイプ | 必須 | 備考 |
|------|-----------|------|------|
| 登録タイプ | トグル | ✅ | 「タスク（未着手）」「アクション（完了）」切替。アクション選択時は期日非表示・完了で保存 |
| タイトル | テキスト | ✅ | |
| アクション種別 | セレクトボックス | | 担当メンバーのroleによって選択肢が変化（下記参照） |
| 詳細・メモ | テキストエリア | | |
| 期日 | 日付ピッカー | | タスク登録時のみ表示 |
| 優先度 | セレクトボックス | | 高 / 中 / 低（タスク登録時のみ表示） |
| 担当メンバー | Memberセレクト | ✅ | 1名のみ |
| 関連先 | Project or Contractセレクト | | どちらか一方のみ選択可 |
| 企業 | 企業検索 | ✅ | 関連先（Project/Contract）選択時は自動セット。未選択時は手動入力必須 |
| 部署 | セレクトボックス | | 企業確定後に登録済み部署が選択肢に表示。Project選択時は自動セット |

**アクション種別選択肢（担当メンバーのrole別）**

| role | アクション種別選択肢 |
|------|-------------------|
| IS | 架電 / メール / フォーム / SNS DM / その他 |
| FS | 架電 / メール / ピック / 社内MTG / 資料作成 / その他 |
| ITSS | 架電 / メール / ピック / 社内MTG / 資料作成 / その他 |
| PERM | 架電 / メール / ピック / 社内MTG / 資料作成 / その他 |
| DSL | 架電 / メール / ピック / 社内MTG / 資料準備 / 開発 / その他 |

## エンジニア向け補足

### 条件表示のルール

| トリガー | 表示制御 |
|---------|---------|
| ContractLine：ステータス = 締結済 | 締結日フィールドを表示 |
| ContractLine：ステータス = リサイクル | 失注・リサイクル理由フィールドを表示 |
| Project：business_type = DSL | 受注確度 / 提案金額 / 受注金額 / 想定粗利 / 失注理由 / 関連契約を表示 |
| Project：ステータス = 受注 | 受注金額フィールドを表示 / ContractLine.statusを締結済に自動更新 |
| Project：ステータス = 失注 | 失注理由フィールドを表示 |
| Company：lead_source = 紹介 | 紹介者フィールドを表示 |
| Task：登録タイプ = アクション | 期日・優先度フィールドを非表示 / status = 完了で保存 |
| Task：関連先（Project/Contract）選択時 | 企業・部署を自動セット |
| Task：関連先 未選択時 | 企業フィールドを必須入力にする |

### 自動セットのルール

| トリガー | 自動セット内容 |
|---------|--------------|
| 企業詳細ページから各レコード追加 | company_idを自動セット |
| ProjectにTaskを紐付け | company_id / department_idを自動セット |
| ContractにTaskを紐付け | company_idを自動セット |
| 案件詳細ページからJob追加 | project_id / company_id / business_typeを自動セット |
| 企業詳細ページからJob追加 | company_idを自動セット |
| JobのProject選択時 | company_id / business_typeを自動セット |
| Project.status変更（DSL） | win_rateの初期値を自動セット（手動上書き可） |
