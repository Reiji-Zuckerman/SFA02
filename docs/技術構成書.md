# SFA02 技術構成書

## アーキテクチャ概要

```
ブラウザ（PC）
  ↕ HTML Service (iframe)
Google Apps Script
  ↕ SpreadsheetApp API
Google スプレッドシート（DB）
```

## フロントエンド構成

### ファイル構成（GAS プロジェクト内）

```
gas-project/
├── Code.gs                  ← メインGASエントリーポイント
├── SheetDB.gs               ← スプレッドシートCRUD操作
├── API.gs                   ← フロントエンドから呼ばれるAPI関数群
│
├── index.html               ← メインHTML（Vue appマウント）
├── css/
│   └── style.html           ← カスタムCSS（<style>タグ）
├── js/
│   ├── app.html             ← Vueインスタンス・ルーター
│   ├── api.html             ← google.script.run ラッパー
│   ├── components/
│   │   ├── Sidebar.html     ← グローバルナビ
│   │   ├── CompanyList.html
│   │   ├── CompanyDetail.html
│   │   ├── MeetingList.html
│   │   ├── ProjectList.html
│   │   ├── JobList.html
│   │   ├── TaskList.html
│   │   ├── MemberList.html
│   │   └── Dashboard.html   ← 全社サマリー
│   └── mixins/
│       ├── filters.html     ← フィルター共通ロジック
│       └── pagination.html  ← ページネーション共通ロジック
└── templates/
    └── modals.html          ← 登録・編集モーダル群
```

> **注意**: GAS HTML Serviceでは `.js` / `.css` ファイルを直接配置できないため、
> すべて `.html` ファイルとして作成し、`<?!= include('ファイル名') ?>` で読み込む。

### Vue.js 設計方針

- **ルーティング**: Hash-based SPA ルーティング（`#/companies`, `#/companies/:id` など）
- **状態管理**: Vue 3 `reactive()` によるシンプルなグローバルストア（Vuex/Pinia不使用）
- **コンポーネント**: `app.component()` でグローバル登録（SFC非使用）
- **API通信**: `google.script.run` を Promise化してラップ

### ルーティング定義

| パス | 画面 | コンポーネント |
|------|------|---------------|
| `#/tasks` | タスク一覧（デフォルト） | TaskList |
| `#/companies` | 企業一覧 | CompanyList |
| `#/companies/:id` | 企業詳細 | CompanyDetail |
| `#/meetings` | 商談一覧 | MeetingList |
| `#/projects` | 案件一覧 | ProjectList |
| `#/jobs` | 求人一覧 | JobList |
| `#/dashboard` | 全社サマリー | Dashboard |
| `#/members` | メンバー管理 | MemberList |

## バックエンド構成（Google Apps Script）

### GASファイル構成

| ファイル | 役割 |
|---------|------|
| `Code.gs` | `doGet()` エントリーポイント、HTML配信 |
| `SheetDB.gs` | スプレッドシートの汎用CRUD関数 |
| `API.gs` | フロントエンドから `google.script.run` 経由で呼ばれる公開関数 |

### API設計（google.script.run で呼び出す関数）

```
// 共通パターン: getXxxList / getXxxById / createXxx / updateXxx / deleteXxx

// 企業
getCompanyList(filters)       → [{id, name, industry, ...}]
getCompanyById(id)            → {company, contracts, departments, contacts, ...}
createCompany(data)           → {id}
updateCompany(id, data)       → {success}

// 部署
getDepartmentsByCompany(companyId) → [{id, name, ...}]
createDepartment(data)             → {id}

// 担当者
getContactsByCompany(companyId) → [{id, name, ...}]
createContact(data)             → {id}
updateContact(id, data)         → {success}

// 契約
getContractByCompany(companyId)   → {contract, lines}
createContractLine(data)          → {id}
updateContractLine(id, data)      → {success}

// 商談
getMeetingList(filters)        → [{id, meeting_date, company_name, ...}]
getMeetingsByCompany(companyId) → [...]
createMeeting(data)            → {id}
updateMeeting(id, data)        → {success}

// 案件
getProjectList(filters)        → [{id, name, status, ...}]
getProjectsByCompany(companyId) → [...]
createProject(data)            → {id}
updateProject(id, data)        → {success}

// 求人
getJobList(filters)            → [{id, job_title, ...}]
getJobsByCompany(companyId)    → [...]
createJob(data)                → {id}

// タスク
getTaskList(filters)           → [{id, title, due_date, ...}]
getTasksByCompany(companyId)   → [...]
createTask(data)               → {id}
updateTask(id, data)           → {success}
completeTask(id)               → {success}

// メンバー
getMemberList()                → [{id, name, role, ...}]

// 全社サマリー
getDashboardData(period)       → {kpi, memberActivity, pipeline, ...}
```

### データ規約

- **ID**: UUID v4 形式（`Utilities.getUuid()` で生成）
- **日時**: ISO 8601 形式（`new Date().toISOString()`）
- **日付**: `YYYY-MM-DD` 形式
- **BOOLEAN**: `TRUE` / `FALSE`（スプレッドシートのネイティブ形式）
- **1行目**: ヘッダー行（カラム名）
- **2行目以降**: データ行

## 開発・デプロイフロー

### ローカル開発

1. このリポジトリでコードを作成・管理
2. GASプロジェクトへは手動コピー or clasp（GAS CLI）でデプロイ

### デプロイ手順

```bash
# clasp を使う場合
npm install -g @google/clasp
clasp login
clasp create --type webapp
clasp push
clasp deploy
```

### 公開設定

- **Web App として公開**
- **実行ユーザー**: 自分（デプロイ者）
- **アクセス権**: 組織内の全員 or リンクを知っている全員
