# SFA02 技術構成書

## アーキテクチャ概要

```
ブラウザ（PC）
  ↕ HTTPS
GitHub Pages（静的ホスティング）
  ↕ fetch() → doGet / doPost
Google Apps Script（Web App）
  ↕ SpreadsheetApp API
Google スプレッドシート（DB）
```

### Vue.js 設計方針

- **ルーティング**: Hash-based SPA ルーティング（`#/companies`, `#/companies/:id` など）
- **状態管理**: Vue 3 `reactive()` によるシンプルなグローバルストア（Vuex/Pinia不使用）
- **コンポーネント**: `app.component()` でグローバル登録（SFC非使用）
- **API通信**: `fetch()` で GAS Web App の URL を呼び出し

### ルーティング定義

| パス | 画面 | コンポーネント |
|------|------|---------------|
| `#/tasks` | タスク一覧（デフォルト） | TaskList |
| `#/companies` | 企業一覧 | CompanyList |
| `#/companies/:id` | 企業詳細 | CompanyDetail |
| `#/meetings` | 商談一覧 | MeetingList |
| `#/projects` | 案件一覧 | ProjectList |
| `#/jobs` | 求人一覧 | JobList |
| `#/dashboard` | 全社サマリー | Dashboard |
| `#/members` | メンバー管理 | MemberList |

## バックエンド構成（Google Apps Script Web App）

### GASファイル構成

| ファイル | 役割 |
|---------|------|
| `Code.gs` | `doGet()` / `doPost()` エントリーポイント、CORSヘッダー付与 |
| `SheetDB.gs` | スプレッドシートの汎用CRUD関数 |
| `API.gs` | アクションごとの処理関数（ルーティング） |
| `Init.gs` | スプレッドシートの初期化（シート・ヘッダー行の自動作成） |

### API設計（REST-like JSON API）

フロントエンドからは `fetch()` で GAS Web App URL にリクエストを送る。

```
GET  ?action=getCompanyList&filters={...}
GET  ?action=getCompanyById&id=xxx
POST {action: "createCompany", data: {...}}
POST {action: "updateCompany", id: "xxx", data: {...}}

GET  ?action=getDepartmentsByCompany&companyId=xxx
POST {action: "createDepartment", data: {...}}

GET  ?action=getContactsByCompany&companyId=xxx
POST {action: "createContact", data: {...}}
POST {action: "updateContact", id: "xxx", data: {...}}

GET  ?action=getContractByCompany&companyId=xxx
POST {action: "createContractLine", data: {...}}
POST {action: "updateContractLine", id: "xxx", data: {...}}

GET  ?action=getMeetingList&filters={...}
GET  ?action=getMeetingsByCompany&companyId=xxx
POST {action: "createMeeting", data: {...}}
POST {action: "updateMeeting", id: "xxx", data: {...}}

GET  ?action=getProjectList&filters={...}
GET  ?action=getProjectsByCompany&companyId=xxx
POST {action: "createProject", data: {...}}
POST {action: "updateProject", id: "xxx", data: {...}}

GET  ?action=getJobList&filters={...}
GET  ?action=getJobsByCompany&companyId=xxx
POST {action: "createJob", data: {...}}

GET  ?action=getTaskList&filters={...}
GET  ?action=getTasksByCompany&companyId=xxx
POST {action: "createTask", data: {...}}
POST {action: "updateTask", id: "xxx", data: {...}}
POST {action: "completeTask", id: "xxx"}

GET  ?action=getMemberList
GET  ?action=getDashboardData&period=thisMonth
```

### CORS対応

GAS Web App は `doGet()` / `doPost()` で `ContentService.createTextOutput(JSON)` を返す。
GAS Web App はリダイレクトを返すため、フロントエンド側で `fetch(url, { redirect: 'follow' })` を使用する。

### データ規約

- **ID**: UUID v4 形式（`Utilities.getUuid()` で生成）
- **日時**: ISO 8601 形式（`new Date().toISOString()`）
- **日付**: `YYYY-MM-DD` 形式
- **BOOLEAN**: `TRUE` / `FALSE`（スプレッドシートのネイティブ形式）
- **1行目**: ヘッダー行（カラム名）
- **2行目以降**: データ行

## 開発・デプロイフロー

### フロントエンド（GitHub Pages）

1. このリポジトリの `index.html` / `css/` / `js/` をGitHub Pagesで配信
2. リポジトリ Settings → Pages → Source: main branch / root

### バックエンド（GAS Web App）

1. `gas/` フォルダの内容をGASプロジェクトにデプロイ

```bash
# clasp を使う場合
npm install -g @google/clasp
clasp login
clasp create --type webapp --rootDir gas/
clasp push
clasp deploy
```

### GAS公開設定

- **Web App として公開**
- **実行ユーザー**: 自分（デプロイ者）
- **アクセス権**: 全員（Anyone）← GitHub Pagesからアクセスするため

### 環境変数

フロントエンド側の `js/api.js` に GAS Web App の公開URL を設定する。

```javascript
const GAS_API_URL = 'https://script.google.com/macros/s/XXXXXXXXX/exec';
```
